# 👥 Экипаж «Полимат-Улея»

Каждый агент — обычный GitHub Actions workflow. Мозг — трёхэтажный:
1. **Copilot CLI** через [`actions/ai-inference@v3`](https://github.com/actions/ai-inference) — если секрет `COPILOT_PAT` задан и Copilot включён.
2. **Локальный GGUF-нейромозг** — `Qwen2.5-0.5B-Instruct` (Q4_K_M, ~490 МБ) запускается на раннере через `llama-cpp-python`. Ни ключей, ни внешних сервисов; кэш через `actions/cache`.
3. **Инстинкты** — эвристики: улей отвечает, даже когда оба верхних этажа спят.

## 🧠 Триаж-агент
- **Файл:** `.github/workflows/triage-agent.yml`
- **Триггер:** `issues: [opened]`
- **Права:** `issues: write`
- **Маршрут:** модель (этаж 1 или 2) возвращает строгий JSON `{labels, summary, plan}`
  → скрипт ставит метки и публикует комментарий. Ответ невнятный — включаются инстинкты.

## 📰 Дайджест-агент
- **Файл:** `.github/workflows/digest-agent.yml`
- **Триггер:** `schedule` (05:30 UTC ежедневно) + `workflow_dispatch` (кнопка)
- **Права:** `contents: write`
- **Маршрут:** собирает коммиты за 24 часа и открытые выпуски → модель пишет
  markdown-дайджест → агент коммитит `DIGEST.md`. Модели нет — дайджест собирается
  по инстинктам из живой статистики.

## 🩺 Доктор улея
- **Файл:** `.github/workflows/doctor-agent.yml`
- **Триггер:** понедельник 06:00 UTC + `workflow_dispatch`
- **Права:** `contents: read`
- **Маршрут:** проверяет этаж 1 (Copilot отвечает?) и этаж 2 (GGUF генерирует?),
  публикует диагноз в лог. Первый, кто узнает о болезни организма.

## 🚧 Как принять в экипаж нового агента

1. Скопируй любой workflow как шаблон.
2. Оставь минимальные права (`permissions:`) — меньше прав, спокойнее улей.
3. Системный промпт пиши на русском, требуй строгий формат ответа.
4. Обязательно `concurrency:` — агенты не должны топтать друг друга.
5. Тестируй через `workflow_dispatch`, прежде чем вешать на события.
6. Для кэша мозга: `actions/cache@v4` с путём `~/brain`.

> Принцип улея: **РОЙ СТРОИТ · ЧЕЛОВЕК ВЕДЁТ · КАЖДЫЙ ШАГ ВИДЕН**.
