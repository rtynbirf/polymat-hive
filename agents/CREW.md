# 👥 Экипаж «Полимат-Улея»

Каждый агент — обычный GitHub Actions workflow + один вызов GitHub Models.
Никаких серверов, ключей и денег: используется `GITHUB_TOKEN` с правом `models: read`.

## 🧠 Триаж-агент
- **Файл:** `.github/workflows/triage-agent.yml`
- **Триггер:** `issues: [opened]`
- **Права:** `issues: write`, `models: read`
- **Маршрут:** модель получает заголовок и тело выпуска → возвращает строгий JSON
  `{labels, summary, plan}` → скрипт ставит метки и публикует комментарий.
- **Страховка:** если модель недоступна или ответила невпопад, агент всё равно
  комментирует выпуск базовым планом и ставит метку `question`.

## 📰 Дайджест-агент
- **Файл:** `.github/workflows/digest-agent.yml`
- **Триггер:** `schedule` (05:30 UTC ежедневно) + `workflow_dispatch` (кнопка)
- **Права:** `contents: write`, `models: read`
- **Маршрут:** собирает коммиты за 24 часа и открытые выпуски → модель пишет
  markdown-дайджест → агент коммитит `DIGEST.md`. Нет событий — нет коммита.

## 🚧 Как принять в экипаж нового агента

1. Скопируй любой workflow как шаблон.
2. Оставь минимальные права (`permissions:`) — меньше прав, спокойнее улей.
3. Системный промпт пиши на русском, требуй строгий формат ответа.
4. Обязательно `concurrency:` — агенты не должны топтать друг друга.
5. Тестируй через `workflow_dispatch`, прежде чем вешать на события.

> Принцип улея: **РОЙ СТРОИТ · ЧЕЛОВЕК ВЕДЁТ · КАЖДЫЙ ШАГ ВИДЕН**.
