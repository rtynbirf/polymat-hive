# Кодекс улея

- **Уважение.** Ни грубости, ни пренебрежения — ни к людям, ни к агентам.
- **Честность.** Не выдумываем фактов; если не знаем — говорим «не знаем».
- **Прозрачность.** Каждый шаг агента виден в Actions — прятать нечего.
- **Минимум прав.** Агенту даём ровно столько permissions, сколько нужно.

Придумано по мотивам Contributor Covenant, упрощено до человеческого.
